**2. [Rule 3 - Blocking] happy-dom v20 has no `GlobalRegistrator`**
- **Found during:** Task 2 test run
- **Issue:** `test-setup.ts` used `import { GlobalRegistrator } from '@happy-dom/global-registrator'` — this export does not exist in happy-dom v20.10.6. The `@happy-dom/` scoped namespace is empty.
- **Fix:** Rewrote `test-setup.ts` to use `import { Window } from 'happy-dom'` and assign `DOMParser` + DOM globals directly to `globalThis`. This provides the W1 DOMParser shim without relying on the removed GlobalRegistrator API.
- **Files modified:** `extension/test-setup.ts`
- **Commit:** `e7592b9`
