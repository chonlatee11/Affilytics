<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Popup ← content script (RawProduct) | Page-derived strings rendered in the popup form |
| Popup → background → POST /api/products/capture | Operator-confirmed payload crosses to the backend |
| Background SW → 127.0.0.1:3000 | Only the background (extension origin) may call localhost (mixed-content rule) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-POPUP-1 | Tampering (XSS) | rendering product name/shop in popup | mitigate | Populate fields via `element.value`/`textContent`, never `innerHTML`, when showing DOM-sourced strings |
| T-02-POPUP-2 | Information Disclosure | content script → localhost direct call | mitigate | Content never fetches localhost; only background SW (extension origin) calls 127.0.0.1 — honors mixed-content rule |
| T-02-POPUP-3 | Spoofing | crafted Shopee page feeding fake data | accept | Operator reviews/edits every field before Save (D-03 review-before-save); single-operator L1 tool |
| T-02-POPUP-4 | Denial of Service | backend offline | mitigate | D-08: graceful offline banner, form preserved, no crash; backend-side TypeBox bounds (02-02) reject oversized/malformed payloads |
| T-02-SC | Tampering | extension packages | mitigate | Packages cleared in RESEARCH Package Legitimacy Audit (Approved, no postinstall); no new installs in this plan |
</threat_model>
