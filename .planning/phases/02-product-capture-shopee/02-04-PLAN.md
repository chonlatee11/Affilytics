| T-02-PARSE-1 | Tampering | reading product name/shop from DOM | mitigate | Use `.textContent` only; values returned as plain strings; popup later renders via textContent (no innerHTML) — blocks XSS via crafted Shopee page |
| T-02-PARSE-2 | Spoofing | malicious Shopee page injecting fake globals | mitigate | Content script runs in ISOLATED world (WXT default); page cannot modify extension globals or messaging |
| T-02-PARSE-3 | Information Disclosure | content script fetching config | mitigate | runtime.getURL scoped to web_accessible_resources matches (shopee only); no localhost fetch from content (mixed-content rule honored) |
</threat_model>
