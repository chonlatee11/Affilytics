## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| extension/dashboard (browser) → backend HTTP | Cross-origin requests; only allowlisted origins permitted |
| LAN → backend socket | Must be unreachable — bind 127.0.0.1 only |
| backend → Meta Graph API | Outbound token verification; token must not leak to logs/responses |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-LAN | Elevation of Privilege | Elysia socket binding | mitigate | `serve.hostname: '127.0.0.1'` (not 0.0.0.0); server.test.ts asserts it (Task 3, FOUND-03) |
| T-1-EXPOSE | Information Disclosure | GET /api/settings + logs | mitigate | explicit column selection excludes access_token_enc; token never logged (Tasks 1–2) |
| T-1-FBVERIFY | Spoofing | pasted FB token | mitigate | verifyToken() against Graph API before persist; invalid → 422 (Tasks 1–2, D-02) |
| T-1-DISCONNECT | Denial of Service | undecryptable token on GET | mitigate | decrypt() null → fbConnected:false, no throw; backend stays up (Task 2, D-04) |
| T-1-KEY | Information Disclosure / Spoofing | encryption key bootstrap | mitigate | setup.ts generates randomBytes(32) into gitignored .env; boot fails fast if missing (Task 3, D-03) |
| T-1-CORS | Spoofing | cross-origin requests | mitigate | @elysiajs/cors allowlist: localhost dashboard + chrome-extension regex only (Task 3) |
| T-1-SC | Tampering | npm supply chain | accept | no new packages installed in this plan; Phase 1 set pre-approved in RESEARCH audit |
</threat_model>
