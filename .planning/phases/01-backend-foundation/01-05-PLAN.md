## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator browser → backend OAuth callback | Inbound `code` + `state` from a redirect; both untrusted until validated |
| backend → Meta Graph API (oauth/access_token, me/accounts) | Outbound; carries FB_APP_SECRET + code + tokens — must never leak to logs/responses |
| backend → SQLite (pages.accessTokenEnc) | Page token at rest — must be encrypted (AES-256-GCM) |
| LAN → backend socket | Unchanged from Plan 03 — bound 127.0.0.1 only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-CSRF | Spoofing/Tampering | /fb-oauth/callback | mitigate | CSRF `state` (randomBytes hex) issued at /authorize, stored server-side, validated + single-use-consumed at /callback; mismatch → 4xx, nothing stored (Task 3) — BLOCK on high: state validation must precede any token exchange |
| T-1-SECRET | Information Disclosure | FB_APP_SECRET in logs/responses | mitigate | secret read only inside exchangeCodeForToken via requireFbOAuthConfig(); never logged, never in any thrown message or response body (Tasks 2-3); grep gate asserts no console line references it |
| T-1-EXPOSE | Information Disclosure | page/user token at rest + in responses | mitigate | page token encrypted via AES-256-GCM before store; callback returns only { ok, pageName }; user token + code never persisted or logged (Task 3, invariant carried from Plan 03) |
| T-1-OPENREDIR | Tampering | redirect_uri in authorize/exchange | mitigate | redirect_uri sourced ONLY from FB_OAUTH_REDIRECT_URI server-side, never from a request param — no attacker-controlled redirect target (Task 3) |
| T-1-REPLAY | Tampering | reused authorization code / state | mitigate | state is deleted (consumed) on first callback use; a replayed state fails the mismatch check (Task 3) |
| T-1-SC | Tampering | npm supply chain | accept | no new packages — uses node:crypto, existing Elysia/Drizzle; Phase 1 package set pre-approved in RESEARCH audit |
</threat_model>
