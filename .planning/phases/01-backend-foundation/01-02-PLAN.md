<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process env → crypto key | BUN_ENCRYPTION_KEY is the only secret bootstrapping all token encryption |
| stored ciphertext → application | Tampered or key-mismatched ciphertext must degrade safely, not crash |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-KEY | Spoofing/Tampering | encryption key bootstrap | mitigate | requireEncryptionKey() validates 32-byte key and fails fast on missing/malformed (Task 2) |
| T-1-CRYPTO | Tampering | AES-256-GCM auth tag | mitigate | GCM auth tag verified on decrypt; new 12-byte IV per encryption prevents replay (Task 2) |
| T-1-DISCONNECT | Denial of Service | undecryptable stored token | mitigate | decrypt() returns null instead of throwing — backend never crashes on key loss (Task 2, D-04) |
| T-1-LAN | Information Disclosure | SQLite WAL/busy_timeout correctness | mitigate | PRAGMAs set on raw connection before drizzle; correct ordering avoids WAL-retrofit migration (Task 2) |
| T-1-MIGRATE | Tampering | schema drift via push | mitigate | tracked generate+migrate only; drizzle-kit push forbidden (Task 3, D-07) |
| T-1-SC | Tampering | npm package supply chain | accept | Phase 1 packages pre-approved in RESEARCH § Package Legitimacy Audit; no new installs in this plan |
</threat_model>
